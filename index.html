Finish in Outlook

  1. Open Outlook Settings → Accounts → Signatures. In Outlook Classic, use File → Options → Mail → Signatures.
  2. Create a signature and paste using Ctrl+V (Windows) or ⌘V (Mac). Keep the source formatting.
  3. Set it as your default for new messages and replies and forwards, then save.
  4. Send yourself a test email to check the layout, links and banner.

Having trouble copying?

Choose “Select signature,” then copy with your keyboard. Don’t select the whole page. If you see plain text when pasting, choose “Keep source formatting” in Outlook. If a copied image disappears, try the published HTTPS page in Microsoft Edge or Google Chrome.
